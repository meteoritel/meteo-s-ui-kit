# 分诊标签

在本地 Markdown 的 `Status:` 中填写对应的状态值。

| 分诊角色 | 状态值 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 要求已明确，可交给 Agent |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 已关闭，停止跟进 |
